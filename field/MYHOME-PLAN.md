# 우리 집 작업 계획

우리 집에서 직접 해볼 것들. 순서와 방법만 적는다.

---

## 1. 주방 후드 — 인덕션 켜면 같이 돈다

### 지금까지 확인된 조건

- 조명 · 좌팬 · 우팬 등 **딸깍 버튼 5개**가 후드 본체에 붙어 있다 (CD3 타입)
- **SwitchBot 으로 안 눌린다**
- **리모컨이 없는 모델**이다
- **후드 전용 차단기가 없다** — 주방 차단기를 내리면 냉장고·인덕션까지 같이 내려간다

마지막 조건 때문에 "버튼 누른 채로 차단기 내렸다 올려서 팬이 도나" 시험은 **쓸 수 없다.**
전원을 끊었다 켜는 방식(스마트 플러그)도 후드만 따로 끊을 수 없으면 애초에 성립하지 않는다.

→ **버튼 접점에 릴레이를 병렬로 다는 길로 간다.**

### 다섯 개를 다 할 필요가 없다

인덕션 연동에 필요한 건 **팬 버튼 하나**다(좌 또는 우). 조명은 나중에 추가하면 된다.
**릴레이 1~2채널이면 충분하다.** 5채널을 잡으면 배선이 다섯 배가 된다.

| 살 것 | 가격 |
| --- | --- |
| ESP-12F WiFi 릴레이 모듈 4채널 | **27,540원** (남는 채널은 나중에 조명용) |
| 있으면 — 릴레이 모듈 4채널 + 보유 ESP | 3,650원 |

### 전원을 어떻게 끊고 작업하나

후드 전용 차단기가 없으므로 선택지는 둘이다.

1. **후드가 콘센트에 꽂혀 있으면 플러그를 뽑는다** — 상부장 안이나 후드 위를 먼저 확인.
   이게 제일 깔끔하다
2. **주방 차단기를 내린다** — 냉장고가 30분 꺼지는 건 괜찮다. 문만 안 열면 된다

작업 중에는 확실히 죽여 놓고, **전압을 잴 때만 잠깐 넣는다.**

### 작업 순서

1. 전원을 끊는다. 후드 버튼을 눌러 **정말 안 켜지는지** 확인하고 시작
2. **컨트롤 패널을 연다** — 보통 필터를 떼면 하판 나사 몇 개다.
   **나사 위치와 분해 순서를 사진으로 남긴다** (조립할 때 이게 제일 아쉽다)
3. **버튼 기판을 본다.** 택트 스위치가 붙은 작은 PCB 다. 여기서 갈린다
   - 기판에 **변압기/SMPS 로 220V 구간과 분리**돼 있고 버튼 쪽이 가는 패턴이면 → 저전압. 진행
   - 버튼에 **굵은 220V 선이 직접** 들어오면 → **여기서 멈춘다**
4. **전압을 잰다** — 전원을 넣고 멀티미터로 버튼 양단. **3.3V 또는 5V** 가 나와야 한다.
   재는 동안 기판 다른 곳에 손대지 않는다. 다 재면 다시 전원을 끊는다
5. **팬 버튼 접점 2가닥에 선을 문다.** 택트 스위치 다리에 납땜이 가장 확실하다
6. **ESP + 릴레이는 후드 밖에 둔다.** 후드 안은 기름때와 고온이라 오래 못 간다.
   선만 빼서 상부장 안이나 후드 위 빈 공간에 놓는다
7. 릴레이 **NO 접점**을 그 2가닥에 연결한다 (버튼과 **병렬**)
8. 조립 전에 시험 — 릴레이를 0.25초 붙였다 떼서 팬이 도는지 본다

### ESPHome 설정

택트 버튼은 누르는 동안만 붙는다. 릴레이를 계속 붙여 두면 **버튼을 계속 누르고 있는 셈**이라
후드가 오작동한다. 짧게 눌렀다 떼는 동작으로 만들어야 한다.

```yaml
# 후드 팬 버튼을 대신 눌러 주는 장치.
# 릴레이를 켜 두는 게 아니라 0.25초만 붙였다 뗀다 — 사람이 버튼을 톡 누르는 것과 같다.
switch:
  - platform: gpio
    pin: GPIO5            # 릴레이 모듈 채널에 맞게
    id: relay_fan
    restore_mode: ALWAYS_OFF

button:
  - platform: template
    name: "주방 후드 팬 버튼"
    on_press:
      - switch.turn_on: relay_fan
      - delay: 250ms
      - switch.turn_off: relay_fan
```

**상태를 모른다는 점을 감안해야 한다.** 버튼을 누르는 것뿐이라 지금 팬이 도는지 HA 가 알 수 없다.
켜기와 끄기가 같은 버튼이면 HA 가 상태를 기억해야 하는데, 한 번 어긋나면 계속 반대로 동작한다.

- `input_boolean` 으로 상태를 들고 다닌다
- **새벽에 하루 한 번 OFF 로 맞춘다** (어긋남 복구)
- 더 확실하게 하려면 나중에 **후드 전원선에 전류 감지**를 붙여 실제 상태를 읽는다

### 인덕션 감지는 나중에

후드를 폰으로 켤 수 있게 되면 그것만으로 매일 쓴다. 자동은 그 다음이다.

- **1단계** 폰·음성으로 켜고 끄기 + **타이머** (켜고 30분 뒤 자동 정지)
- **2단계** 분전반 CT 클램프 약 **8.5만** → 인덕션 전력이 올라가면 후드 자동
- **3단계** 전력이 0 이 되고 **10분 뒤** 정지 (잔열·연기)

## 2. 욕실 환풍기 — 리모컨이 있어 쉽다

**리모컨이 있으니 스위치를 안 건드린다.** Tapo H110 IR 허브에 신호를 학습시키면 끝이다.

- IR 허브 **38,800** + 모션 센서 **9,900** = **48,700원**
- 사람 감지 → ON 신호 / 움직임 없이 60분 → OFF 신호

IR 은 단방향이라 지금 켜져 있는지 모르지만, 이 자동화는 상태를 몰라도 된다 —
들어오면 ON, 한 시간 지나면 OFF 를 보내면 그만이다.

## 3. 간접조명 1구간 — Driver·SMPS 실습

- LED 스트립 + Driver 로 한 구간만 실제로 달아 본다
- **Driver 용량 계산**을 직접 해본다 (스트립 길이 × m당 W, 여유 20%)
- 정전류 / 정전압 차이를 실물로 확인
- Zigbee 디머로 조광 — 저와트에서 깜빡임(플리커)이 나는지

---

## 순서

```
1. 후드 컨트롤 패널 열어 버튼 기판 확인 (0원)   ← 저전압인지 220V인지가 전부다
2. ESP 릴레이 주문 (2.7만) · 팬 버튼 하나만
3. ESPHome 으로 버튼 누르기 + 타이머 자동화
4. 욕실 환풍기 IR (4.9만)
5. 간접조명 1구간
6. 인덕션 CT (8.5만) → 후드 완전 자동
```

단계마다 **사진**을 남긴다. 특히 후드는 분해 사진이 없으면 조립할 때 고생한다.
