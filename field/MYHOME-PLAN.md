# 우리 집 먼저 — 남의 집에 가기 전에 내 집에서 재 본다

지인에게 권하는 것을 내 집에서 해보지 않았다. **첫 세 집을 찾기 전에 내 집이 0번째 집이다.**

목적은 세 가지다.

1. **진입 상품(7.5만·2시간)이 정말 2시간인지** 재 본다 — 견적의 근거가 추정뿐이다
2. **조명 설계 역량이 있는지** 확인한다 — Driver·SMPS 를 도면만 보고 설계할 수 있는지가
   `견적.md` 4-8 신설 항목의 전제인데, 아직 미확인이다(5장)
3. **사진과 영상**을 남긴다 — `/lab` 과 제안서에 쓸 실물 증거

---

## 1번 과제 — 인덕션 켜면 후드가 같이 돈다

제일 하고 싶은 것이고, 시작하기에도 맞다. 두 부분으로 나뉜다.

```
[인덕션이 켜졌다]  →  감지  →  [후드 팬을 켠다]  →  요리 끝나면 잠시 뒤 끈다
```

### 후드를 켜는 쪽 — 우리 집 후드는 딸깍 버튼이다

조명 / 좌팬 / 우팬 버튼이 따로 있고 **누르면 고정되는 래치 방식**이다.
벽 스위치가 아니라 후드 본체에 붙어 있어서 **스마트 스위치로 교체할 수 없다.**

| 방법 | 비용 | 후드 분해 | 원복 | 판단 |
| --- | --- | --- | --- | --- |
| **A. 전원을 끊었다 켠다** | 플러그 **15,210** | 불필요 | 즉시 | **먼저 이것부터.** 팬 버튼을 눌러 둔 채로 두고 전원만 제어하면, 전원이 들어오는 순간 팬이 돈다 |
| **B. 버튼을 기계로 누른다** | SwitchBot 봇 **38,800** | 불필요 | 즉시 | A 가 안 되면(전원 복구 시 버튼 상태가 초기화되는 후드) 이쪽 |
| C. 버튼 접점에 릴레이 병렬 | Shelly Plus 1 **71,760** | 필요 | 어려움 | 가장 확실하지만 후드를 뜯는다. **고객 집에서는 쓰지 않는다** |

**A 를 먼저 시험하는 이유**: 가장 싸고, 아무것도 안 뜯고, 실패해도 잃는 게 없다.
그리고 **A 가 되면 고객 집에서도 쓸 수 있다** — 물리 시공을 하지 않는 우리 모델에 맞는다.

> **먼저 확인할 것**
> - [ ] 후드가 **콘센트에 꽂혀** 있나, 아니면 **직결**인가 — 직결이면 A 는 불가, B 로 간다
> - [ ] 팬 버튼을 누른 채로 **차단기를 내렸다 올리면** 팬이 바로 도나
>       (이게 A 의 성립 조건이다. 전원 복구 시 초기화되는 후드면 A 는 안 된다)

### 인덕션이 켜진 걸 아는 쪽

인덕션은 220V 전용 회로에 **직결**돼 있어 스마트 플러그를 낄 수 없다. 세 가지 길이 있다.

| 방법 | 비용 | 분전반 | 정확도 | 판단 |
| --- | --- | --- | --- | --- |
| **분전반 CT 클램프** | 약 **8.5만**(해외구매) | **열어야 함** | 높음 — kW 단위로 즉시 | 정석. `견적.md` 5장 (10)번 미확인 항목이 이걸로 풀린다 |
| 후드 아래 온도 센서 | **14,900** | 불필요 | 낮음 — 느리고 헛detection | 물이 끓어야 반응. 끄는 판단에는 쓸 만하다 |
| 손으로 시작 | 0 | 불필요 | — | 폰·음성으로 "요리 시작". **1단계로는 이걸로 충분하다** |

**단계를 나눈다.** 처음부터 분전반을 열 이유가 없다.

- **1단계** 후드 팬을 폰·음성으로 켜고 끈다 + **타이머**(켜고 나서 30분 뒤 자동 정지)
  → 이것만으로도 매일 쓴다. 그리고 여기서 A/B 중 뭐가 되는지가 판가름난다
- **2단계** CT 클램프를 달아 **인덕션 전력 → 후드 자동**. 분전반은 차단기 내리고 작업
- **3단계** 끄는 조건을 다듬는다 — 전력이 0 이 되고 **10분 뒤** 정지(잔열·연기)

### 살 것 (1단계)

```
Tapo P110M 스마트 플러그      15,210     A 안
SwitchBot 봇                  38,800     B 안 (A 실패 시)
```

**둘 다 사지 말고 A 부터.** 1.5만으로 되는지 먼저 본다.

## 2번 과제 — 욕실 환풍기 (진입 상품 그대로)

`/lab` 과 견적서에 **7.5만·2시간**으로 적어 둔 그 상품이다. 내 집에서 먼저 해서
**그 숫자가 맞는지 재 본다.** 남한테 팔 값을 내가 안 해보고 정할 수는 없다.

- 스위치 교체 **54,900** + 모션 센서 **9,900** = **64,800원**
- 자동화: 사람 감지 → 환풍기 ON / 움직임 없이 60분 → OFF

**시간을 잰다.** 스톱워치로 아래를 따로 적는다.

| 단계 | 예상 | 실제 |
| --- | --- | --- |
| 차단기 내리고 기존 스위치 탈거 | 15분 | |
| 스마트 스위치 결선·고정 | 30분 | |
| 허브 페어링 | 15분 | |
| 모션 센서 부착·페어링 | 15분 | |
| 자동화 작성·시험 | 30분 | |
| **합계** | **1h 45m** | |

2시간을 넘으면 **견적서의 7.5만을 올려야 한다.** 넘지 않으면 그대로 간다.

## 3번 과제 — 조명 설계 역량 확인

`견적.md` 4-8 에 **조명·전기 설계 검토 15만 / 간접조명·다운라이트 구간 설계 10만**을 넣었는데,
**내가 이걸 할 수 있는지가 아직 미확인이다.** 구축기 글쓴이도 컨설팅을 받고서야 이해했다고 적었다.

우리 집은 리모델링 중이 아니라 배선을 새로 못 깐다. 대신 **한 구간만 실제로 해본다.**

- [ ] 간접조명 1구간 (거실 또는 침실 헤드) — LED 스트립 + Driver
- [ ] **Driver 용량 계산**을 직접 해본다 (W = 스트립 길이 × m당 W, 여유 20%)
- [ ] 정전류/정전압 차이를 실물로 확인
- [ ] Zigbee 디머로 조광 — 저와트에서 깜빡임(플리커)이 나는지

**여기서 막히면 4-8 의 설계 항목은 팔 수 없다.** 그때는 이지엉클 같은 곳과 제휴하는 쪽으로
방향을 바꾼다(5장 미확인).

## 하는 순서

```
1. 후드 A 안 시험 (1.5만, 30분)        ← 이번 주. 되는지만 본다
2. 후드 1단계 완성 (타이머까지)         ← 되면 바로
3. 욕실 환풍기 (6.5만, 시간 측정)       ← 진입 상품 검증
4. 간접조명 1구간 (Driver 실습)         ← 설계 역량 확인
5. 인덕션 CT (8.5만, 분전반)           ← 1~4 가 끝난 뒤
```

각 단계가 끝나면 **사진과 30초 영상**을 남긴다. `/lab` 의 욕실 환풍기 슬라이드에
**실제 우리 집 영상**이 들어가면 설득력이 달라진다 — 지금은 글로만 설명하고 있다.
