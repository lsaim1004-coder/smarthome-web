# 방문 체크리스트

시간이 얼마나 걸리는지 재는 것이 첫 세 집의 목적이다. **재지 않으면 이번 방문은 의미가 없다.**

---

## 방문 전 — 전화로 10분

집에서 준비할 것을 정하려면 이것만 알면 된다.

| 물어볼 것 | 왜 |
| --- | --- |
| 인터넷 어디 쓰세요? (KT·SKB·U+) | 통신사 공유기면 2.4GHz 분리가 안 될 수 있다 |
| 공유기가 통신사 것 하나인가요, 따로 사신 게 있나요 | 이중 NAT·대역 분리 판단 |
| 에어컨·TV·세탁기 **브랜드와 대략 연식** | 계정 연동이 되는 모델인지. 10년 넘으면 IR 허브가 필요하다 |
| 가전 앱을 쓰시나요? 계정은 누구 명의인가요 | **배우자 명의면 그분이 계실 때 가야 한다.** 이거 하나로 방문이 한 번 늘어난다 |
| 로봇청소기 있으세요? | 브랜드에 따라 연동 경로가 다르다 |
| 제일 불편한 게 뭐예요? | 자동화를 여기서 뽑는다. 기능 목록부터 들이밀지 않는다 |
| 전세인가요 자가인가요 | 스위치를 바꾸려면 집주인 동의 |

**미리 알려드릴 것**

- 가전 앱 **비밀번호는 제가 받지 않습니다.** 연동할 때 직접 입력해 주세요
- 스위치를 바꾸는 동안 **차단기를 내립니다** (5~10분)
- 떼어낸 스위치는 보관해 두었다가 원하시면 되돌려 드립니다

## 집에서 — 가기 전날

- [ ] `setup-ha.sh` 돌린 미니PC, 온보딩까지 완료
- [ ] USB 동글 꽂아 둠 (`/dev/serial/by-id/` 에 보이는지 확인)
- [ ] `docker compose ps` 로 세 컨테이너 Up 확인
- [ ] 랜선 1.5m
- [ ] 기기 상자 개봉해서 **미리 페어링 가능한 것은 집에서 해 둔다** (플러그·센서는 대부분 된다)
- [ ] 드라이버, 검전기, 절연 테이프 (스위치 교체가 있으면)

## 현장 — 시간을 잰다

각 칸에 **실제 분**을 적는다. 기억으로 쓰지 말고 폰 스톱워치로.

| 단계 | 예상 | 실제 | 막힌 것 |
| --- | --- | --- | --- |
| 미니PC 연결·HA 접속 | 10분 | | |
| Wi-Fi 상태 확인 (2.4GHz 분리 여부) | 10분 | | |
| 가전 계정 연동 (고객이 입력) | 20분 | | |
| 기기 페어링 | 30분 | | |
| 스위치 교체 (있으면) | 30분/개 | | |
| 자동화 만들기 | 30분 | | |
| 사용법 설명 | 20분 | | |
| **합계** | **약 2.5h** | | |

**막힌 것을 반드시 적는다.** 다음 집에서 같은 데서 막히면 그게 표준화할 지점이다.

## 현장 — 확인할 것 (견적.md 5장 11번)

- [ ] 공인 IP 가 있나 (CGNAT 인가) — `curl -s ifconfig.me` 와 공유기 WAN IP 비교
- [ ] 공유기 관리자 화면에 들어갈 수 있나
- [ ] **2.4GHz 분리가 되나** — 안 되면 IoT 전용 공유기(ipTIME 5~8만)가 견적에 들어간다
- [ ] IKEA 센서가 SmartThings Station 에 **직접** 붙나 (보증 미확인 항목, 2-10)
- [ ] Tapo H110 으로 학습한 IR 가전이 SmartThings 에 어떤 종류로 보이나
