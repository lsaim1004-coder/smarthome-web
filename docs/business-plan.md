# 스마트홈 IoT 옵션 사업 기획안

> Smart Home Option Service 의 사업 구상 원문. 요약은 저장소 [README](../README.md) 의 "서비스 구상" 참고.
> 2026-09-11 기준. 부록의 검토 메모는 기획안 작성 시점의 미결 사항 정리.

## 1. 사업 개요

**사업명**: Smart Home Option Service — 인테리어 + 네트워크 + IoT + 자동화를 한 번에

### 핵심 사업모델

```
[인테리어 업체]
       │
       │ 스마트홈 옵션 제안
       ▼
[스마트홈 전문업체]
       │
       ├─ 사전 설계
       ├─ 제품 선정
       ├─ 네트워크 구축
       ├─ IoT 설치/연동
       ├─ 자동화 설정
       └─ 입주 후 A/S
       │
       ▼
     [고객]
```

인테리어 업체 입장에서는 새로운 공사를 배우거나 직접 IoT를 관리할 필요 없이 옵션 하나를 추가할 수 있게 만드는 것.

## 2. 고객에게 무엇을 팔 것인가?

핵심은 기기를 파는 게 아니라 **'완성된 스마트홈'을 파는 것**.

- ✗ "스마트 플러그 하나 설치해드릴게요."
- ✓ "퇴근하면 조명·커튼·에어컨이 알아서 맞춰지고, 외출하면 전원과 조명이 자동으로 정리되는 스마트홈을 만들어드립니다."

실제 구성은 고객의 가전 브랜드에 맞춰 조합.

### 연동 가능한 영역

조명/스위치 · 커튼/블라인드 · 도어락 · 에어컨 · 냉장고 · 세탁기/건조기 · 로봇청소기 · 공기청정기 · 가습기 · 스마트 플러그 · 센서 · 월패드 · Wi-Fi / AP / 유선 네트워크 · SmartThings / Matter / Google Home 등

SmartThings, ThinQ, Google Home, Matter/Zigbee, AP·공유기 구성까지 직접 부딪혀본 경험이 있기 때문에 단순 IoT 판매업체보다 차별화할 수 있는 부분이 있음.

## 3. 가장 중요한 차별점

사업의 핵심을 "IoT 설치업체"가 아니라 **"스마트홈 컨설팅 + 커미셔닝 업체"**로 잡는 것을 추천.
실제 고객이 가장 힘들어하는 건 제품 구매가 아니기 때문.

### 고객이 실제로 겪는 문제

```
삼성 가전   → SmartThings
LG 가전     → ThinQ
커튼        → 별도 앱
도어락      → 별도 앱
센서        → Zigbee / Matter
공유기      → Wi-Fi 문제
월패드      → 아파트별 호환성 문제
```

제품은 다 사놨는데:
- "왜 얘는 SmartThings에 안 잡히지?"
- "커튼은 Google Home에는 있는데 SmartThings에는 왜 안 나오지?"
- "IoT 기기가 자꾸 끊겨요."
- "도어락이 가끔 연결이 안 돼요."

이걸 해결해주는 게 사업의 핵심 가치.

## 4. 인테리어 업체에게 팔 상품

인테리어 업체에는 복잡한 기술 설명을 하면 안 됨. **3~4개 옵션으로 단순화**.

### BASIC — 스마트홈 준비 (예상 판매가 30~50만원)
- Wi-Fi 환경 점검
- 공유기/AP 구성
- IoT 기본 설계
- SmartThings/Matter 허브 구성
- 스마트 플러그/센서 일부
- 기본 자동화

### STANDARD — 스마트홈 패키지 (예상 판매가 100~180만원) ← **주력 상품**
- 스마트 조명/스위치
- 커튼/블라인드
- 스마트 플러그
- 센서
- 도어락 연동
- SmartThings 구성
- 기본 자동화 5~10개
- 입주 후 세팅

### PREMIUM — 올인원 스마트홈 (예상 판매가 250~500만원+)
- 네트워크 설계
- AP/유선망
- 스마트 조명
- 전동커튼
- 도어락
- 센서
- 가전 연동
- 로봇청소기
- 에어컨
- Matter/SmartThings
- 장면(Scene) 자동화
- 입주 후 교육
- 유지관리

여기서부터는 집마다 커스터마이징.

## 5. 특히 인테리어 업체가 좋아할 이유

"IoT 사업 같이 해보시죠."라고 하면 별로 관심이 없을 수 있음. 대신:

> "지금 고객에게 인테리어 옵션으로 스마트홈을 추가 판매할 수 있습니다. 설치와 사후관리는 제가 하고, 업체는 추가 매출과 옵션 상품을 확보할 수 있습니다."

### 인테리어 업체의 이득

① **공사금액 증가** — 기존 인테리어 3,000만원 + 스마트홈 옵션 150만원 → 객단가 상승
② **추가 영업상품** — 조명·중문·붙박이장·커튼·가전에 "스마트홈 패키지"를 하나 더
③ **고객 만족도 증가** — 신축/구축 아파트 입주 고객의 "인테리어 끝났는데 스마트홈은 누가 해주지?"를 업체가 해결해주는 것처럼 보이게

## 6. 수익 구조

**기기 마진 + 설치비 + 설계비 + 유지관리비 4단 구조** 추천.

150만원짜리 옵션 판매 예시:

| 항목 | 금액 예시 |
|---|---|
| IoT 기기 | 90만원 |
| 설치/시공 | 30만원 |
| 설계/세팅 | 20만원 |
| 유지관리 | 10만원 |
| **총 판매가** | **150만원** |

인테리어 업체에 **소개/판매 수수료 10~20%**.

```
고객
 │
 └─ 150만원
      │
      ├─ 제품/자재 90
      ├─ 설치 30
      ├─ 운영/세팅 10
      └─ 사업자 마진 20
                    │
             인테리어 업체
                 소개수수료
```

실제 비율은 원가와 설치 난이도를 보고 조정.

## 7. 여기서 중요한 전략 — 처음부터 모든 IoT를 다 하지 않는 것

삼성 / LG / 샤오미 / 로보락 / Aqara / Tuya / Matter / Zigbee / KNX / 월패드... 다 하려고 하면 **A/S 지옥**.

초기에는 표준 플랫폼을 하나 정하고 감.

- **1차 표준**: SmartThings + Matter + Zigbee
- Google Home은 고객이 원하는 경우 추가
- 가전은 삼성/LG 등 브랜드별 앱을 유지하면서 가능한 것만 플랫폼에 통합

## 8. 인테리어 공사 단계에 끼워 넣기

IoT 업체가 인테리어 끝난 다음 들어가면 할 수 있는 게 제한됨. 인테리어 계약 시점부터:

```
① 인테리어 상담
        ↓
② 스마트홈 옵션 선택
        ↓
③ 전기/통신 설계
        ↓
④ 인테리어 공사
        ↓
⑤ IoT 설치
        ↓
⑥ 가전 입고
        ↓
⑦ 스마트홈 통합
        ↓
⑧ 입주
        ↓
⑨ 자동화 세팅
```

전기공사 단계에서 스마트 스위치/센서/통신선까지 반영 가능.

## 9. 특히 추천하는 상품 — "입주 스마트홈 패키지"

대표상품. 신축/구축 아파트 입주 스마트홈 패키지:

① Wi-Fi 최적화 → ② 스마트 조명 → ③ 전동커튼 → ④ 도어락 → ⑤ 센서 → ⑥ 스마트 플러그 → ⑦ 가전 연동 → ⑧ SmartThings 통합 → ⑨ 자동화 → ⑩ 사용자 교육

고객 입장에서 "기기 여러 개 사서 내가 연결해야 하는 서비스"가 아니라 **"입주하는 날 스마트홈이 완성되어 있는 서비스"**.

## 10. 자동화가 진짜 상품

가격을 올릴 수 있는 핵심이 자동화.

| 시나리오 | 동작 |
|---|---|
| **외출** | 도어락 잠금 → 거실 조명 OFF → 에어컨 OFF → 커튼 CLOSE → 필요 없는 IoT OFF |
| **귀가** | 도어락 OPEN → 현관 조명 ON → 거실 조명 ON → 커튼 OPEN |
| **취침** ("잘게") | 조명 OFF → 커튼 CLOSE → 에어컨 설정 → 불필요한 기기 OFF |
| **청소** | 외출 감지 → 로봇청소기 실행 |

이런 생활 시나리오를 만들어주는 것이 제품보다 훨씬 높은 부가가치를 만듦.

## 11. 직접 겪었던 문제를 사업 아이템으로

경험한 것들을 그대로 서비스 항목으로:

| 서비스 | 항목 |
|---|---|
| **스마트홈 진단** | Wi-Fi 음영지역, 2.4GHz IoT 연결 문제, 5GHz 최적화, AP 위치, 공유기 위치, 유선 네트워크, 단자함 구성 |
| **스마트홈 통합** | SmartThings, Matter, Zigbee, Google Home, 제조사 앱 |
| **스마트홈 설치** | 커튼, 센서, 스위치, 플러그, 도어락 |
| **스마트홈 커미셔닝** | 기기 등록, 방/공간 설정, 자동화, 장면, 음성 제어, 고객 교육 |

→ 단순 설치업체가 아니라 **스마트홈 시스템 통합업체(SI)**로 포지셔닝.

## 12. 초기 사업 시작 방법

회사를 먼저 크게 만드는 것보다 **기존 인테리어 업체 1~3곳을 대상으로 테스트**.

### 1단계 — PoC
인테리어 업체 1곳 선정 → 고객에게 스마트홈 옵션 3종 제공 → 5~10세대 시공 → 문제점 수집 → 표준화

### 2단계 — 상품화
제품을 고정. 예: 스위치 A · 센서 B · 플러그 C · 커튼 모터 D · 도어락 E · 허브 F
가능한 한 검증된 제품으로 표준화 → 설치시간과 A/S 급감.

### 3단계 — 인테리어 업체 확대
1개 업체 → 3개 업체 → 10개 업체.
이때부터는 직접 시공만 하는 게 아니라 **인테리어 업체가 고객에게 판매 → 설계/시공/관리** 구조로 전환.

## 13. 인테리어 업자에게 보여줄 실제 영업 문구

> "사장님, 인테리어 고객들이 요즘 가전은 스마트한데 집 전체를 연결하는 건 직접 못 하거든요.
>
> 그래서 인테리어 공사할 때 스마트홈 옵션을 같이 판매하는 서비스를 만들어보려고 합니다.
>
> 사장님은 기존 인테리어 견적에 스마트홈 옵션만 추가해서 판매하시고, 제품 선정·설계·설치·연동·입주 후 세팅은 제가 담당하는 방식입니다.
>
> 사장님 입장에서는 공사 객단가가 올라가고 새로운 기술을 직접 관리할 필요가 없습니다."

## 14. 최종적으로 만들고 싶은 회사 구조

```
                 스마트홈 플랫폼 사업
                         │
          ┌──────────────┼──────────────┐
          ↓              ↓              ↓
       인테리어        건설/분양       개인 고객
        업체             업체
          │              │              │
          └──────────────┼──────────────┘
                         ↓
                 스마트홈 SI
                         │
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
      설계              설치              유지보수
        │                │                │
        └────────────────┼────────────────┘
                         ↓
                  월 유지관리 서비스
```

일회성 설치 매출만 보는 게 아니라 **유지관리 매출**까지.

### 스마트홈 케어 (예)
- 연 1회 네트워크 점검
- IoT 연결 상태 점검
- 자동화 점검
- 기기 교체/추가
- 신규 가전 연동
- Wi-Fi 음영 개선

## 이 사업의 핵심

> "IoT 제품 판매"로 시작하면 작은 사업이고,
> "인테리어 업체를 통한 스마트홈 SI"로 가면 사업이 커질 수 있다.

인테리어 업체가 고객을 이미 확보하고 있다는 점이 굉장히 큼.
고객을 한 명씩 찾아다닐 필요 없이 **인테리어 업체 1곳 확보 → 월 5~10개 현장 확보**가 가능한 구조.

## 부록. 검토 메모 (2026-09-11, Claude 검토 — 기획안 원문에는 없는 내용)

- **수수료 산식 모순**: 150만 예시에서 사업자 마진 20만인데 소개수수료 10~20%(15~30만)를 주면 마진 0 이하. 수수료를 기기가에 얹거나 마진 구조 재설계 필요.
- **법규**: 스마트 스위치 교체는 전기공사업법, UTP 배선·AP 설치는 정보통신공사업법 적용 가능. "경미한 공사" 예외 범위 또는 등록 업체와의 협업 구조 확인.
- **중성선(N선) 문제**: 한국 아파트 스위치 박스 대부분 N선 없음 → 무중성선 스위치 제품 선정 또는 공사 단계 배선. 공사 단계 진입의 실질적 근거.
- **누락 영역**: 난방(온도조절기), 가스밸브, 월패드 연동(2022 세대망 분리 의무화 이후 신축은 제약 큼). 국내 스마트홈 수요에서 비중 큼.
- **도어락**: 삼성SDS·게이트맨 등 국내 도어락은 SmartThings 직접 연동이 제한적. "도어락 OPEN → 조명 ON" 시나리오가 실제 가능한 제품군 확정 필요.
- **플랫폼 종속**: SmartThings 클라우드·허브 정책 변경 리스크. 고객 삼성계정으로 세팅(사업자 계정 금지), 원격 유지관리 시 개인정보 동의 절차.
- **경쟁 조사**: 헤이홈(고퀄), 시하스, 코맥스/코콤, 삼성 스마트홈 시공파트너 등 이미 입주 패키지를 파는 사업자와의 차별점 정리.
- **PoC KPI 미정의**: 세대당 시공 시간, 입주 후 30일 내 A/S 콜 수, 재방문율을 PoC 단계에서 측정해야 표준화 근거가 됨.
