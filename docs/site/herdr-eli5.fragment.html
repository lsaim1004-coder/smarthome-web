AI들은 그대로 둡니다. 우리만 하나 쳐 주는 겁니다.

안쪽은 네 겹으로 되어 있습니다

바깥에서 안으로 갈수록 작아집니다. 제일 안쪽이 실제로 일하는 AI입니다.

워크스페이스 프로젝트 하나, 보통 저장소 하나

탭 화면을 어떻게 쪼갤지 정한 배치 한 장

패인 진짜 명령이 돌아가는 터미널 한 칸

에이전트 그 칸에서 코드를 만지는 AI 한 마리

지금 무슨 상태인지 알려 줍니다

화면과 프로세스를 들여다보고 다섯 가지 중 하나로 표시합니다. 사람이 일일이 확인하지 않습니다.

working 한창 일하는 중입니다. 그냥 두면 됩니다.
blocked 질문을 띄우고 멈췄습니다. 내 대답을 기다립니다.
done 내가 안 보는 사이에 다 끝냈습니다.
idle 결과를 이미 확인했고, 지금은 조용합니다.
unknown herdr가 알아보지 못하는 프로그램입니다.

터미널과 프로세스를 실제로 소유합니다.

창을 닫아도, SSH가 끊겨도 그대로 돌아갑니다.

tmux를 써 봤다면

tmux 입장에서 AI 도구는 그냥 아무 명령어입니다. herdr는 그게 AI라는 걸 압니다.

기준tmuxherdr
칸을 나눠 쓰기된다된다
창을 닫아도 살아 있기된다된다
누가 멈췄는지 알려 주기안 된다목록에 바로 뜬다
다른 컴퓨터까지 한 화면에따로 붙어야 한다같이 뜬다
마우스로 조작단축키 위주클릭과 드래그로 된다
AI에게 일을 시켜 두기직접 타이핑명령 하나로 시키고 기다린다

세 줄로 시작합니다

설치합니다. 실행 파일 하나입니다.

# 윈도우 (PowerShell)
irm https://herdr.dev/install.ps1 | iex

# 맥 · 리눅스
curl -fsSL https://herdr.dev/install.sh | sh

실행합니다. 처음이면 시작하고, 두 번째부터는 아까 그 화면으로 돌아갑니다.

herdr

AI를 한 마리 풀어 놓고 일을 시킵니다. --wait를 붙이면 끝날 때까지 기다려 줍니다.

herdr agent start reviewer --kind codex --pane w1:p2
herdr agent prompt reviewer "결제 모듈 리뷰해줘" --wait
