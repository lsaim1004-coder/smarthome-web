### 1-3. 시장 관찰

**가격대 분포**
- 저가(5만~30만원): 플랫폼 건당 시세(숨고 평균 23만), 크몽 10~30만, 아카라 출장 5만+항목별, 단품 방문설치(커튼레일 10.9만). 기기 1~4개 연동 수준.
- 중가(50만~200만원): **상품화된 오퍼가 거의 없음.** 가이드 문서의 추정치("25평 전체 스위치 교체 50~120만", "거실 조명 자동화 50~120만")와 기기+설치 패키지(도어락 46~47만)만 존재.
- 고가(300만~2,000만원+): 견적비교 플랫폼 가이드(강남 300~2,000만, 대전 200~800만)와 커뮤니티 실견적(30평대 2,000만+). 조명 회로 수·난방 존·월패드 연동으로 티어가 갈림.

**흔한 과금 방식**: 기기 + 항목별 설치비(아카라), 개소당 인건비(스위치 교체 1.5~3만, 중성선 5~10만/개소), 시간당(전기기술자 5~10만), 정액 패키지(크몽), 회로·존 기준 티어(미소). 대형 브랜드·인테리어 채널은 전부 견적 문의.

**A/S·유지관리**: 공개된 것은 "제품 1년 무상 A/S"가 대부분. **시공 하자 보증·자동화 재설정 보증 기간을 명시한 업체는 없음.** 통신사만 월 구독형.

**우리 기획과 비교한 시사점**
1. 가격을 공개한 시공 사업자가 사실상 없어 **티어별 정가 공개 자체가 차별점**이 된다. BASIC 30~50만은 숨고 평균(23만)·크몽(10~30만)과 직접 비교되므로 기기 포함 여부·자동화 개수·교육을 명확히 표기해야 저가 플랫폼과 구분된다.
2. **STANDARD 100~180만원은 상품화된 경쟁 오퍼가 비어 있는 구간.** 반면 PREMIUM 250~500만원은 견적비교 플랫폼 최저 티어("30평대 200~400만", "시작형 300~600만")와 겹치므로 조명 회로 수·난방 존·커튼 개수 같은 같은 단위로 스펙을 적어야 비교에서 이긴다.
3. 원가 벤치마크: 출장 5만, 스위치 설치 5만/개, 커튼 14만/개, 중성선 공사 5~10만/개소, 전기기술자 5~10만/시간. 25평 전체 스위치 교체가 자재 포함 50~120만이므로 STANDARD 원가 설계의 상한 검증 기준.
4. 인테리어 채널은 이미 한샘(삼성 스마트싱스)과 아카라라이프(2026-03, 설계 검증 33만·파트너 시공)가 진입. 도면 단계 컨설팅이 유료로 성립한 사례가 있으니 우리 설계 항목도 별도 과금 근거가 있고, 반대로 "왜 아카라 파트너 대신 우리인가"(멀티 브랜드·앱 통합·하자 보증)에 답해야 한다.

1. **가격 변동성이 크다.** 같은 SKU 라도 다나와 최저 대비 쿠팡·공식몰가가 1.3~1.5배(Aqara M3 172,190 vs 253,000; Station 36,000 vs 40,700). 견적은 최저가 조달을 전제로 하되 재고 상황에 따라 일반가로 사는 경우를 4장의 "일반 합계"로 병기.
2. **Aqara 정발 vs 직구.** 정발(아카라라이프·에스알테크)은 T1/P2 센서, H2 스위치, M3/M100 허브 중심이고 **Curtain Driver E1, 모션 P1, H1 무중성선 스위치는 정발이 없다.** 직구(E1 약 $101)는 싸지만 리전 펌웨어·A/S 불가·드라이버 호환 차이가 있어 고객 납품용으로는 정발 또는 국내 유통 모델(SwitchBot, 헤이홈)을 쓴다.
3. **무중성선 스위치 주의.** 국내 아파트 스위치 박스는 대부분 중성선이 없다. Aqara 무중성선 2구는 구형 재고이며 저와트 LED(3W 이하) 깜빡임 이슈, 시하스 SBM-300 은 콘덴서 추가 시공 필수, 헤이홈 피카 2선식은 헤이홈 허브 종속. **STANDARD 이상은 시공 전 등기구 확인이 필수**이고, 중성선 추가 공사(개소당 5~10만원)가 필요하면 견적에 별도 반영.

## 3. 서버 PC — 세대용 HA 와 중앙 관제

### 운영 방식 2트랙
| 구분 | **A. 세대 설치형** | **B. 중앙 관제형** |
| --- | --- | --- |
| 형태 | 패키지에 소형 PC(N100 미니PC)를 포함해 **고객이 구매**, 스마트홈 담당이 집 안에 HA 를 설치하고 계정 연동·자동화까지 세팅 | 세대 PC 는 동일하게 설치하되 **아웃바운드 터널**로 사업자 관제 서버에 연결, 상시 모니터링·원격 점검 |
| 과금 | 일회성: 기기 + 설치 + 세팅 (+ 선택 A/S 건별) | 초기 설치비 + **월/연 구독**(스마트홈 케어) |
| 원가 요소 | 세대 PC 1대(아래 표), 설치 인건비 | A 의 원가 + 관제 서버(N100 + UPS) 1회 + 터널/알림 서비스 월 요금(무료 티어 가능) + 관제 인건비 |
| 데이터 | 집 안에만 저장. 원격 점검은 고객 동의 시 임시 연결 | 상태·오류 정보가 관제 서버로 전달 → 동의 절차, 전송 항목 최소화 |
| 장애 대응 | 고객 연락 후 원격/방문 | 끊김·오동작 선제 감지 → A/S 콜 감소 |
| 적합 대상 | 인테리어 옵션 판매(견적 1줄), 개인정보 민감 고객, PoC | 다세대(건설·분양), 유지관리 매출, 파트너 A/S 부담 경감 |

**권장 순서**: PoC(5~10세대)는 A 로 시작해 설치 표준을 만들고, 세대 10곳 이상에서 B 의 관제 서버를 도입한다. B 의 세대 측 하드웨어는 A 와 같으므로 A 고객을 나중에 B 로 전환할 수 있다(터널 에이전트만 추가).

### 왜 서버가 필요한가
- 세대마다 **Home Assistant(HA)** 가 로컬에서 돌아야 제조사 앱 계정 연동(ThinQ · Mi Home · SmartThings)과 Zigbee/Matter 기기를 한 화면으로 모을 수 있습니다. 클라우드 HA(Nabu Casa)는 원격 접속만 제공하고 실행 하드웨어는 여전히 필요합니다.
- 여러 세대를 **중앙에서 관제**(연결 끊김 감지, 자동화 오동작 알림, 원격 점검)하려면 사업자 쪽에 별도 서버가 있어야 하고, 그 위에 여러 서비스가 함께 떠야 합니다.

### 네트워크 · 방화벽 문제와 해결 방향
| 문제 | 내용 | 해결 |
| --- | --- | --- |
| 세대 공유기 NAT | 고객 집은 사설 IP 뒤에 있어 밖에서 들어갈 수 없음. 포트포워딩은 보안·유지관리 부담 | 세대 HA 가 **밖으로 나가는 터널**을 유지 (Tailscale/Headscale, WireGuard, Cloudflare Tunnel). 인바운드 포트 개방 없음 |
| 통신사 공유기·이중 NAT | 아파트 월패드망·통신사 공유기 뒤에 다시 공유기가 있는 구조 | 아웃바운드 터널은 이중 NAT 에서도 동작. UDP 차단 시 TCP 폴백(Cloudflare Tunnel) |
| 세대 IP 변경 | 유동 IP | 터널이 세대 식별을 대신하므로 IP 무관 |
| 관제 서버 노출 | 관제 화면·VPN 허브가 인터넷에 노출 | 관제 서버도 Cloudflare 뒤(Access 인증)나 VPN 안에서만 접근 |
| 개인정보 | 세대 기기 상태가 사업자 서버로 전달됨 | 원격 점검 동의 절차, 전송 항목 최소화(상태·오류만), 세대별 접근 권한 분리 |

### 중앙 관제 서버에 떠야 하는 서비스 (예)
```
[세대 A] HA + Matterbridge (+ MQTT) ──터널──┐
[세대 B] HA ...                          ──터널──┤   [관제 서버 (N100 미니PC)]
[세대 C] HA ...                          ──터널──┘    ├─ VPN 허브 (Headscale 또는 Tailscale 계정)
                                                     ├─ 모니터링 (Uptime Kuma / Prometheus + Grafana)
                                                     ├─ 알림 (Telegram/카카오 알림톡 연동)
                                                     ├─ 원격 접속 게이트 (Cloudflare Tunnel + Access)
                                                     ├─ 백업 저장 (세대 HA 스냅샷)
                                                     └─ 고객·현장 관리 웹 (이 저장소의 smarthome-web)
```
- 서비스 6~8개가 컨테이너로 동시에 뜨므로 **RAM 16GB, SSD 512GB, 4코어(N100/N150 급)** 를 최소 사양으로 봅니다. 세대 수 30~50까지는 N100 한 대로 충분하고, 그 이상은 N305 또는 두 대로 분리합니다.
- 관제 서버는 **UPS** 를 붙여 정전 시 알림 오탐을 막습니다. 세대 HA 는 UPS 없이도 됩니다(재부팅 후 자동 복구).

- **가격 검증 범위**: 다나와·공식몰은 직접 확인, 쿠팡은 봇 차단으로 다나와 가격비교 표·가격추적 스니펫으로 대체. IKEA·Tapo·Aqara P2 단가는 2-10 에서 공식몰로 재확인 완료. ThingsOne T1 CCTV(92,000)와 Aqara M3 137,500 · 열림 P2 39,688 참고치는 재현되지 않아 "확인 불가".
- **IKEA 센서의 SmartThings Station 직접 페어링은 공식 보증 미확인**(Thread 보더 라우터 필요로만 안내). PoC 첫 세대에서 실측 후 표준 확정. 실패 시 DIRIGERA(149,000) 추가 또는 Aqara T1 계열로 대체 → BASIC 기기 원가 +10~15만.
- **경쟁사 실견적 부재**: 헤이홈·한샘·삼성·LG·코맥스·코콤·스타트홈·와츠매터는 공개 가격이 없다. 미소 가격대는 SEO 가이드, 클리앙 2,000만원은 개인 사례 1건. **34평 도면으로 3~4곳 미스터리 쇼핑(견적 요청)** 이 다음 단계.
- **아카라라이프 토탈 설치 서비스 단가 미확인**(1-6). 30평대 정찰제라고만 공개돼 있다. 시공을 넘기는 모델에서 이 금액은 **우리 견적의 4-9 시공비 칸을 대체할 수 있는 실제 숫자**라 우선순위가 높다. 공식몰 문의 또는 삼성닷컴 입점 페이지에서 확인할 것.
- **시공 단가 가정**: 4-8·4-9 의 시공비는 아카라 공개 설치 단가(스위치 5만/개 등)를 보수적으로 낮춰 잡은 값(스위치 3.5만/개)이다. 실제 인테리어 업체 전기팀 단가는 협의 대상이며, 업체가 자기 인건비로 흡수할 수도 있다. **업체 1곳과 실제 단가를 맞춰 보기 전까지 4-9 는 추정치다.**
- **커미셔닝 시간 가정**: 설계 + 현장 커미셔닝을 START 4h ~ FULL 16h 로 잡았다. 시공팀과 같은 날 움직일 수 없으면 현장 방문이 2회로 늘어 시간이 30~50% 증가할 수 있다. **PoC 에서 실측할 것**(세대당 방문 횟수·대기 시간).
- **무중성선·중성선 공사**: Aqara 무중성선 2구는 구형 재고분이며 저와트 LED 깜빡임 가능. 중성선 추가 공사(개소당 5~10만원)가 필요한 세대는 업체 견적에 별도 항목으로 들어간다. **이 판단과 책임은 이제 업체 전기팀 몫이다.**
- **재고**: 품절·단종 SKU 가 많아(아카라 H1·T1·M3 공식몰, 시하스, 헤이홈 피카, HA Yellow) 견적 시점마다 대체 모델을 확인해야 한다.
- **법규·세무**: 물리 시공을 하지 않으면서 전기공사업·정보통신공사업 등록 이슈는 해소됐다. 남은 것은 부가세 신고 방식과 카드 매출 세액공제, 그리고 **기기를 우리가 매입·재판매하므로 통신판매업 신고 필요 여부**다. 하도급형(모델 1)은 업체와 세금계산서 거래라 카드수수료가 없다.
